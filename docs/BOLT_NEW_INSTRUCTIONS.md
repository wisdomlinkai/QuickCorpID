# 🚀 Instructions: Using Bolt.new for Frontend Redesign

## Step 1: Choose Your Design Style

Open `BOLT_NEW_PROMPTS.md` and choose one of the 5 design options:

1. **Modern Minimalist** ✨ (Recommended) - Clean, professional, Stripe-like
2. **Playful & Vibrant** 🎨 - Colorful, engaging, Notion-like
3. **Corporate & Professional** 🏢 - Traditional, trustworthy, HSBC-like
4. **Modern SaaS Dashboard** 📊 - Data-driven, Linear-like
5. **Glassmorphism** 💎 - Trendy, blur effects, Apple-like

## Step 2: Go to Bolt.new

1. Visit: https://bolt.new
2. Create a new project

## Step 3: Copy & Paste

1. **Copy** your chosen prompt from `BOLT_NEW_PROMPTS.md`
2. **Paste** it into bolt.new's prompt box

## Step 4: Attach Current Code Files

Upload these files so bolt.new understands your current implementation:

### Required Files to Attach:

**Option A: Attach specific files** (Recommended)
- `src/pages/HomePage.tsx` - Current home page
- `src/components/Navbar.tsx` - Current navigation
- `src/i18n/translations.ts` - All text content
- `tailwind.config.js` - Color configuration

**Option B: Attach entire project**
- Zip the entire `src` folder
- Include `package.json` and `tailwind.config.js`

## Step 5: Generate

Click "Generate" or "Create" in bolt.new

## Step 6: Review Output

Bolt.new will generate:
- HTML files with Tailwind CSS classes
- Component structure
- Layout design

## Step 7: Share Output

**Option A: Copy HTML code**
- Copy the generated HTML from bolt.new
- Paste into a new file here
- I'll convert to React components

**Option B: Share bolt.new project link**
- If bolt.new provides a shareable link
- Share it with me
- I can view and extract the code

## Step 8: Implementation

I will:
1. Convert HTML to React TypeScript components
2. Wire up with existing AuthContext
3. Connect to existing API endpoints
4. Add React Router navigation
5. Integrate with existing translations
6. Test all functionality
7. Deploy to AWS Amplify
