## 🎨 Option 1: Modern Minimalist Design

**Design Style:** Clean, minimal, lots of white space, subtle animations

```
I need you to redesign the frontend for a Hong Kong business identity SaaS platform called "iBiz Smart 智企通". 

**Current State:**
I have a working React + TypeScript + Vite + Tailwind CSS application, but the frontend design needs improvement. I want you to generate HTML + Tailwind CSS code that I can convert to React components.

**Project Details:**
- Name: iBiz Smart (English) / 智企通 (Chinese)
- Purpose: Hong Kong business digital identity and CorpID registration platform
- Target Users: Hong Kong SMEs, self-employed, F&B outlets, transport operators
- Year: 2026

**Design Requirements:**
- Style: Modern minimalist - clean, lots of white space, subtle animations, professional
- Colors: Primary blue (#2563eb), Secondary teal (#14b8a6), gradients
- Typography: Clean sans-serif, excellent hierarchy
- Layout: Generous padding, card-based sections, clear CTAs
- Mobile: Fully responsive, mobile-first approach
- Interactions: Subtle hover effects, smooth transitions (300ms), micro-animations

**Pages to Generate (HTML + Tailwind CSS):**

1. **Home Page (/)** - Landing page with:
   - Hero section (title, subtitle, CTA buttons, trust badges)
   - Benefits section (4 cards with icons)
   - Target users section (4 user type cards)
   - Bottom CTA section
   - Use this exact content:
     * Hero title (EN): "Register CorpID in 5 Minutes"
     * Hero title (ZH): "輕鬆註冊 CorpID，5 分鐘搞定"
     * Subtitle (EN): "The easiest way for Hong Kong SMEs to get their Digital Corporate Identity"
     * Trust badges: "Sandbox Tested", "256-bit SSL", "Digital Policy Office"
     * Benefits: "Quick & Easy", "Government Approved", "Secure & Trusted", "Bilingual Support"

2. **Login Page (/login)** - Clean login form with:
   - Email input
   - Password input
   - Sign In button
   - Forgot password link
   - Register link

3. **Register Page (/register)** - Multi-step form (4 steps):
   - Step 1: Business information (BR number, company name, email, phone)
   - Step 2: Identity verification (ID type, ID number, document upload)
   - Step 3: Role & authorization (role selection, checkboxes)
   - Step 4: Review & submit (summary, submit button)
   - Progress indicator
   - Back/Next navigation

4. **Dashboard Page (/dashboard)** - Protected dashboard with:
   - Welcome message
   - Stats cards (CorpID status, documents count, etc.)
   - Quick actions section
   - Recent activity list

5. **Organisations Page (/organisations)** - Organisation management:
   - Organisation list
   - Create organisation modal/form
   - Invite member functionality
   - Organisation switcher

6. **CorpID Page (/corpid)** - CorpID connection:
   - QR code display
   - Connection status
   - Status polling indicator
   - Instructions

7. **Documents Page (/documents)** - Document management:
   - Upload area (drag & drop)
   - Documents list
   - Download/share actions

8. **Settings Page (/settings)** - Settings with tabs:
   - Profile tab (name, email, phone, language)
   - Organisation tab
   - Notifications tab
   - Security tab

9. **Pricing Page (/pricing)** - Pricing tiers:
   - Free tier
   - Premium tier (highlighted as "Most Popular")
   - Enterprise tier
   - Feature lists for each

10. **About Page (/about)** - About page with:
    - Mission section
    - What is CorpID section
    - Team/contact section

**Navigation:**
- Fixed navbar with logo, nav links (Home, Login, Register, Dashboard, Pricing, About), language switcher (EN/中文)
- Footer with contact info, links, copyright: "© 2026 iBiz Smart 智企通"

**Technical Requirements:**
- Use Tailwind CSS utility classes
- Use Lucide React icons (import paths will be added later)
- Semantic HTML5 structure
- Accessible (ARIA labels, proper heading hierarchy)
- No JavaScript needed (just HTML structure, we'll add React logic)
- Mobile-responsive breakpoints: sm (640px), md (768px), lg (1024px), xl (1280px)

**Design Inspiration:**
- Stripe.com - clean, professional, excellent use of gradients
- Vercel.com - minimal, modern, great typography
- Linear.app - subtle animations, excellent spacing

Please generate clean, well-structured HTML with Tailwind CSS classes. Use placeholder images/icons where needed (I'll replace with Lucide icons). Include comments to mark different sections.
```
